    Settings

    Use a shortcut like Ctrl+Alt+Y, or leave blank to disable. Changes apply immediately. You can also use Manage Extension Shortcuts in about:addons.

    Dashboard keyboard shortcuts

    Use a key like Escape, Delete, or Ctrl+Shift+K. Meta means Command on macOS. Leave blank to disable. These apply inside Tabview; text editing and normal Tab navigation remain available. Save to apply.

    Firefox does not expose per-tab RAM to extensions. Loaded/unloaded labels show tab state, not memory usage. Paste about:processes into the address bar to see browser memory diagnostics; processes can contain several tabs. Firefox blocks extensions from opening this page directly.
